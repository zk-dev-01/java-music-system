# java-music-system
## Overview
A simple music application made in Java that allows users to play songs, rate them, and provide feedback through the console or GUI interface.

## Tech Stack
- Java
- Java Swing (GUI)

## Features
- Play and navigate through songs
- Rate songs and provide feedback
- GUI interface built with Java Swing
- Includes a premium/upgrade section

## What I Learned
- Core object-oriented programming concepts in Java
- Building graphical user interfaces using Java Swing
- Structuring a multi-class application
- Handling user input and event-driven programming

## How to Run

### Option 1: Console Version
1. Compile all Java files:
   javac *.java

2. Run the console application:
   java FinalProject
---------------------------------

### Option 2: GUI Version (Java Swing)
1. Compile all Java files:
   javac *.java

2. Run the GUI application:
   java GUI

---------------------------------
